# Encounter destination art

Destination illustrations used during the approach sequence.

- combat.svg — generic combat opponent; individual enemy is revealed when combat begins
- elder.svg — conversation / mentor encounter
- shrine.svg — shrine / blessing encounter
- church.svg — church / temple encounter
- inn.svg — rest / traveler encounter
- monument.svg — mystery / lore encounter
- merchant.svg — trade encounter
- mystery.svg — unexplained roadside encounter

These are intentionally reusable destination assets. The encounter system can later swap in proper illustrated PNG/WebP assets without changing the game logic.
