# Scrolling and Strolling

A side-scrolling narrative roguelite inspired by wandering swordsman stories.

## Core Loop

1. Character automatically walks to the right.
2. An event appears.
3. Player chooses an action.
4. Outcome is resolved.
5. Journey continues.

## MVP Goal

Build the smallest playable version possible.

### Systems

- Auto movement
- Event engine
- Choice resolution
- Three stats
  - Honor
  - Skill
  - Fame
- Simple combat encounters
- Rewards and penalties

### State Flow

Walking -> Event -> Outcome -> Walking

## Sample Event

Bandit Ambush

Choices:
- Fight
- Avoid
- Pay Toll
