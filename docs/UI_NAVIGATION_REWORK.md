# Footer Navigation Rework

Approved UI direction.

## Navigation Philosophy

Each footer button has a single responsibility.

- Menu = administrative actions
- Character = character sheet
- Journey = world map / travel history (future)
- Gear = equipment (future)
- Skills = techniques and mastery (future)

No shared modal should be opened by multiple footer buttons.

## UX Rules

- Only one page visible at a time.
- Footer always remains visible.
- No nested modals.
- No shared menu overlays.
- Navigation should feel similar to a polished mobile RPG.
